Alter Table

Sobre o vídeo

O vídeo apresenta o comando ALTER TABLE no SQL, essencial para modificar tabelas existentes sem a necessidade de recriá-las. O autor demonstra três operações fundamentais: o ADD, utilizado para incluir novos atributos, o CHANGE, que permite renomear ou ajustar colunas existentes, como alterar o tipo ou tamanho de um dado, e o DROP, que remove atributos que não são mais necessários, otimizando o fluxo de trabalho no banco de dados.

O vídeo explica o funcionamento do comando UPDATE em bancos de dados, que serve para modificar valores já inseridos em uma tabela. O tutorial demonstra a sintaxe básica utilizando a cláusula SET para definir a alteração e reforça a importância crítica de usar o WHERE para filtrar qual linha será atualizada.

Loja Riverson (Alter Table)

Clique aqui para assistir!

Sobre o vídeo

Este vídeo demonstra como atualizar valores em uma tabela de produtos da “Loja do Riverson” com o comando UPDATE no SQL. O tutorial exemplifica a alteração do preço de um item específico e, posteriormente, mostra como aplicar um reajuste percentual de 10% em vários produtos simultaneamente. Durante o processo, ele explica a importância de utilizar a cláusula WHERE para evitar alterações indesejadas em todo o banco de dados e ensina como desativar a trava de segurança do sistema (SQL safe updates) para permitir a execução de atualizações em lote.
